# Meow Meow Tarot

A web-based fortune telling platform featuring interactive daily tarot predictions, life path numerology calculations, and zodiac horoscopes.

## Prerequisites
- **Node.js** (v18.0 or higher)

## Installation
```bash
npm install
```

## Running the Application
```bash
npm start
```

## Local URL
Open your web browser and navigate to:
**http://localhost:3000**
